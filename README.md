# How Everyday Things Work: 3D models

Interactive 3D models that go with the book *How Everyday Things Work* by Uvais.
Open the site, pick a machine, and switch between **How it works** and **Anatomy**.

Live site: https://hmduwis.github.io/how-everyday-things-work-3d/

Machines: fridge, microwave, pressure-cooker, gas-stove, mixer, fan, led, ac, inverter, ro,
phone, touchscreen, wifi, upi, gps, engine, brakes, lift, traffic, bicycle.
Open one directly by adding `#name`, for example `.../#fridge`.
